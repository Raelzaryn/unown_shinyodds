Introduction

You probably know the Tanoby Ruins if you played the FireRed and LeafGreen versions. In this case, you know that these Ruins contain Unown, and that the latter can represent each of the 26 letters of the Latin alphabet, plus the '?' and the '!'. What you may not know is that in Generation 3, the letter that each Unown represents is defined by its PID, a value of its own and different from one individual to another. This same PID also defines many other things, such as nature, ability (if it can have 2, which is not the case with Unown), but above all, it defines whether it is shiny or not. However, Unown’s letters are not evenly distributed within the possible PID range, but above all, according to your ID and your secret ID, the shiny PID range does not contain these letters in the same proportions. This inevitably leads to a change in the odds of having a Unown shiny according to the letter it represents.

Technical explanation

First of all, a small reminder of what is the PID: It is a number determined randomly, of a size of 32 bits that can be represented in binary form (base 2), decimal (base 10, the one used every day), or hexadecimal (base 16). As explained in the preamble, the PID allows you to define a whole bunch of things (gender, nature, ability, shiny character, and even the location of Spinda spots). The PID can take all the values between the minimum value and the maximum value, listed in this table:

BinaryDecimalHexadecimal
Min00000000 00000000 00000000 00000000000000000
Max11111111 11111111 11111111 111111114 294 967 295FFFFFFFF

After that, I will use 0(2) to represent a binary number and 0(16) to represent a hexadecimal number. If nothing is specified, the number is then in its decimal form.

What we know is that there are a total of 232 PID possible, and 219 give a shiny. Only, these 219 PID will not be the same according to your ID/SID couple. On the other hand, Unown's letter changes with the PID. Let’s see how all this is determined in detail:

To determine the shiny character, the highlighted bits of the number below are used:

00000000 00000000 00000000 00000000(2)

To determine the letter of Unown, the highlighted bits of the number below are used to form another number, denoted L:

00000000 00000000 00000000 00000000(2)

L = 00000000(2)

The letter is determined by A=L % 28 (%: modulo, or remainder of the Euclidean division of L by 28).
For A from 0 to 25, the letters from A to Z, 26 and 27 correspond respectively to "?" and "!".

First observation: The blue and pink parts are not used to determine the shiny character.

Second observation: The letter is determined by a number that can range from 0 to 255, modulo 28. But 256 is not a multiple of 28, and therefore some letters will be more represented than the others. This is the case with the letters A, B, C and D which are represented 10 times (the others 9 times).

For the green and red parts, there can be shiny only if the xor function between the two numbers returns a certain value (denoted PIDUV, for PID Unown Value, between 0 and 3), and this value changes according to the secret ID and ID, which is expressed by IDUV (ID Unown Value). For there to be shiny, we must have IDUV = PIDUV. IDUV is then determined as follows:

TID = 00000000 00000000(2)
SID = 00000000 00000000(2)

IDUV = 00(2) xor 00(2)

For example, if IDUV = 0, there is 4/16 of PID corresponding to the ABCD group, and therefore 1/16 of A, 1/16 of B, 1/16 of C and 1/16 of D.

Determining the probability

First, it is necessary to determine the number of PIDs that represent each of the letters. It is therefore necessary to observe the number of times that each letter appears among the 256 possible values of L (it has been seen previously that A, B, C and D appear 10 times, the others 9 times).

For each value of L, we have 224 PID (by removing the 8 determining bits L). Each of the letters of the ABCD group is represented by 167 772 160 PID (10*224), the others are each represented by 150 994 944 PID (9*224).

Then, it is necessary to determine the number of shiny PIDs that represent each of the letters. There are a total of 219 = 524288 PID shiny (and which are among the 232 PID possible, but are not the same according to the ID/SID pair). The distribution of letters is expressed in the previous table (and therefore depends on IDUV). For IDUV = 0, the ABCD group represents 4/16 of the shiny PIDs, i.e. 524288*4/16 = 131072. If we want the number of shiny PIDs giving the letter A, it is enough to divide by 4, or 32768.

So the probability that Unown A is shiny with an IDUV = 0 is 32 768 / 167 772 160 = 1/5120.

Application for shiny hunting

Well, it's very nice all these technical explanations to finally say that the probabilities change, but what are the applications that can be made for shiny hunting?

It can be seen that the operation is in fact similar to Cute Charm in Generation 4, but applied to the letters of Unown (but having less drastic changes). Indeed, it will be possible to choose preferentially a letter from Unown. Since the only place you can find Unown in Generation 3 is the Tanoby Ruins, I will simply list all the possibilities.

For those who have not read the “Technical explanation” section, you will see an IDUV variable in the tables below. You can calculate this value with the following formula, where TID is your Trainer ID and SID your Secret ID:

IDUV = ((TID xor SID) / 256) % 4

(xor: exclusive or; for this, the calculator of your computer can help; %: modulo, here too, the Mod function of the calculator can help)

Conclusion

This particular operation concerning the forms of Unown allows us to have an influence on the probability of falling on such form of Unown in shiny, in the same way as Cute Charm in Generation 4. This can be useful if one targets a particular form, but remains very limited (few forms really benefit from it) even if there are some interesting cases (such as the Unown I of the Weepth Chamber or the Unown M of the Rixy Chamber). Another thing to know, you are not in 1/8192 when shiny hunting Unown in Generation 3 (just like with Cute Charm in Generation 4).
